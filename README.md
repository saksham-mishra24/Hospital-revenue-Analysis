

# 🏨 Hotel Revenue Analysis

A complete data analysis project focused on understanding hotel booking trends, revenue patterns, and customer behavior using data analytics tools.

---

## 📌 Project Overview

This project analyzes hotel booking data to:

* 📊 Understand revenue trends
* 🛏 Analyze booking patterns
* ❌ Identify cancellation impact
* 📈 Improve pricing & occupancy strategy
* 💰 Maximize hotel revenue

The goal is to extract business insights that help hotel management make data-driven decisions.

---

## 🎯 Problem Statement

Hotels face challenges such as:

* High cancellation rates
* Seasonal demand fluctuations
* Revenue loss from underpricing or overpricing
* Low occupancy during off-season

This project aims to analyze historical booking data and identify key revenue drivers.

---

## 🗂 Dataset Information

The dataset includes information like:

* Hotel type
* Booking date
* Arrival date
* Lead time
* Room type
* Market segment
* Cancellation status
* Average Daily Rate (ADR)
* Total revenue

## 🔍 Exploratory Data Analysis (EDA)

The following analysis was performed:

### 1️⃣ Data Cleaning

* Handling missing values
* Removing duplicates
* Fixing data types

### 2️⃣ Revenue Analysis

* Revenue by hotel type
* Revenue by month
* ADR comparison

### 3️⃣ Cancellation Analysis

* Cancellation rate
* Revenue loss due to cancellations
* Cancellation by market segment

### 4️⃣ Booking Trends

* Seasonal booking trends
* Peak months
* Weekend vs weekday booking

---

## 📊 Key Insights

* Resort hotels generate higher ADR but have seasonal dependency.
* City hotels have higher booking frequency.
* High lead time bookings show higher cancellation probability.
* Certain market segments contribute more to revenue stability.
